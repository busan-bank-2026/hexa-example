# loan-errors 대출 실패 알리기

종류: 기능
배울 것: 도메인 예외를 어댑터가 메시지로 바꾸기

## 먼저 볼 문제

대출 중인 책을 빌리면 프로그램이 멈춘다
- M1이 B1을 빌린 뒤 M2가 B1을 빌리면 IllegalStateException으로 프로그램이 끝난다
- 없는 책 번호 B9를 빌리면 NullPointerException으로 끝난다. 메시지로는 무엇이 틀렸는지 알 수 없다
- 회원 번호를 비우고 빌려도 IllegalArgumentException으로 끝난다
- 대출 중이 아닌 책을 반납하면 반납했습니다가 나온다

```
1 대출  2 반납  3 목록  0 종료
> 1
회원 번호: M2
책 번호: B1
Exception in thread "main" java.lang.IllegalStateException: 이미 대출 중인 책입니다
	at hexa.domain.Book.borrow(Book.java:15)
```

## 할 일

- S1 대출 중인 책을 대출하면 콘솔 메뉴가 이미 대출 중인 책입니다를 보여 주고 메뉴로 돌아간다. 빌린 사람은 바뀌지 않는다
- S2 없는 책 번호로 대출하거나 반납하면 서비스가 책을 찾을 수 없습니다 오류를 낸다. 콘솔 메뉴는 그 메시지를 보여 주고 메뉴로 돌아간다
- S3 회원 번호나 책 번호를 비우고 대출하면 콘솔 메뉴가 회원 번호가 비었습니다나 책 번호가 비었습니다를 보여 주고 메뉴로 돌아간다. 저장 파일에 대출이 남지 않는다
- S4 대출 중이 아닌 책을 반납하면 도메인 책이 거절한다. 콘솔 메뉴는 대출 중이 아닌 책입니다를 보여 주고 메뉴로 돌아간다
- S5 서비스와 도메인은 실패를 예외로만 알리고 콘솔 글을 모른다. 예외를 잡아 메시지로 바꾸는 곳은 콘솔 메뉴 하나다

## 실패가 지나가는 길

| 실패 | 던지는 곳 | 예외 | 메시지 |
|---|---|---|---|
| 빈 값 | 입력 모델 대출 요청 | IllegalArgumentException | 회원 번호가 비었습니다, 책 번호가 비었습니다 |
| 없는 책 번호 | 서비스 | IllegalArgumentException | 책을 찾을 수 없습니다 |
| 이미 대출 중 | 도메인 책 | IllegalStateException | 이미 대출 중인 책입니다 |
| 대출 중이 아님 | 도메인 책 | IllegalStateException | 대출 중이 아닌 책입니다 |

- 잘못된 값은 IllegalArgumentException, 지금 상태로는 안 되는 일은 IllegalStateException이다
- 둘 다 자바 표준 예외라서 콘솔 메뉴가 도메인을 몰라도 잡을 수 있다
- 안쪽은 무엇이 틀렸는지 메시지에 담는다
- 바깥 어댑터는 그 메시지를 자기 방식으로 보여 준다

## 실행 예시

```
1 대출  2 반납  3 목록  0 종료
> 1
회원 번호: M1
책 번호: B1
객체지향의 사실과 오해 대출했습니다
1 대출  2 반납  3 목록  0 종료
> 1
회원 번호: M2
책 번호: B1
이미 대출 중인 책입니다
1 대출  2 반납  3 목록  0 종료
> 1
회원 번호: M2
책 번호: B9
책을 찾을 수 없습니다
1 대출  2 반납  3 목록  0 종료
> 2
책 번호: B2
대출 중이 아닌 책입니다
1 대출  2 반납  3 목록  0 종료
> 0
프로그램을 끝냅니다
```

## 흐름

메뉴 -> 대출 유스케이스 -> 서비스와 도메인이 실패하면 메시지를 담은 예외 -> 콘솔 메뉴가 잡아 메시지 한 줄 -> 메뉴로 돌아가기

## 그대로인 것

- 바른 값으로 대출, 반납, 목록을 하면 결과 글은 borrow-command와 같다
- 두 번째 입구의 실행 결과는 borrow-command와 같다
- 저장 파일 모양은 그대로다

## 안 하는 것

- 예외 종류마다 다른 안내 글(예: 대출 실패 머리말): 안 만듦. 메시지를 그대로 보여 준다
- 직접 만든 예외 클래스: 안 만듦. 콘솔 메뉴가 도메인을 모르게 표준 예외를 쓴다
- 저장 파일 읽기 쓰기 실패 알리기: 안 만듦. 저장 파일이 깨졌을 때 알리기와 같은 일이다
