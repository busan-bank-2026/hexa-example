# use-case-port 대출 유스케이스 포트

종류: 리팩터
배울 것: 들어오는 포트, 드라이빙 어댑터, 테스트도 입구

## 먼저 볼 문제

콘솔 입력 없이는 대출을 실행해 볼 수 없다
- 대출을 해 보려면 프로그램을 띄우고 메뉴에서 번호, 회원 번호, 책 번호를 직접 쳐야 한다
- 서비스가 콘솔에서 직접 읽어서 다른 곳에서 서비스를 부를 수 없다

## 할 일

- S1 대출과 반납을 유스케이스 포트로 연다. 대출은 회원 번호와 책 번호를, 반납은 책 번호를 받는다
- S2 서비스는 콘솔을 쓰지 않는다. 받은 값으로 대출과 반납을 하고 결과로 책을 돌려준다
- S3 콘솔 메뉴를 드라이빙 어댑터로 옮긴다. 메뉴가 입력을 읽어 포트를 부르고 결과 글을 찍는다
- S4 콘솔 없이 포트를 부르는 두 번째 입구를 만든다. 실행하면 대출과 반납 결과를 찍는다

## 두 번째 입구 실행 결과

```
B1을 M1에게 대출: 객체지향의 사실과 오해
B1 반납: 객체지향의 사실과 오해
```

## 그대로인 것

- 콘솔 메뉴의 동작과 글은 layered-loan과 같다
- 대출 중인 책을 다시 대출하면 오류로 멈춘다
- 서비스가 저장 클래스를 직접 만드는 것은 그대로다. store-port 장에서 고친다
