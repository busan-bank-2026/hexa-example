# store-port 저장 포트

종류: 리팩터
배울 것: 나가는 포트, 드리븐 어댑터

## 먼저 볼 문제

저장 방식을 바꾸려면 서비스를 고쳐야 한다
- 서비스가 메모리 저장 클래스를 필드에서 직접 만든다
- 파일이나 DB로 바꾸려면 서비스 코드를 열어 그 줄을 바꿔야 한다

## 할 일

- S1 서비스가 쓰는 저장을 나가는 포트로 연다. 책 찾기와 책 저장 두 가지다
- S2 서비스는 저장 클래스를 만들지 않고 포트를 받는다. 무엇을 넣을지는 Main과 두 번째 입구가 정한다
- S3 메모리 저장을 포트를 구현한 드리븐 어댑터로 바꾼다

## 그대로인 것

- 콘솔 메뉴와 두 번째 입구의 동작과 글은 use-case-port와 같다
- 처음 책 3권은 그대로다
- 대출 중인 책을 다시 대출하면 오류로 멈춘다

## 안 하는 것

- 파일 저장 어댑터: file-store 장
- 패키지 나누기: hexagon-packages 장
