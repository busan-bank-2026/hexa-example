# layered-loan 계층형 대출

종류: 기능
배울 것: 문제의 출발점이 되는 계층형 코드

## 할 일

- S1 시작하면 메뉴를 보여준다. 메뉴에 없는 번호를 고르면 메뉴를 다시 보여준다
- S2 대출을 고르고 회원 번호와 책 번호를 넣으면 책을 대출한다
- S3 대출 중인 책을 다시 대출하면 거절한다. 오류로 프로그램이 멈춘다
- S4 반납을 고르고 책 번호를 넣으면 책을 반납한다. 반납한 책은 다시 대출할 수 있다
- S5 종료를 고르면 프로그램을 끝낸다

## 처음 책

| 책 번호 | 제목 |
|---|---|
| B1 | 객체지향의 사실과 오해 |
| B2 | 클린 아키텍처 |
| B3 | 도메인 주도 설계 첫걸음 |

## 실행 결과

```
도서 대출 프로그램을 시작합니다
1 대출  2 반납  0 종료
> 1
회원 번호: M1
책 번호: B1
객체지향의 사실과 오해 대출했습니다
1 대출  2 반납  0 종료
> 2
책 번호: B1
객체지향의 사실과 오해 반납했습니다
1 대출  2 반납  0 종료
> 0
프로그램을 끝냅니다
```

## 흐름

메뉴 -> 번호 고르기 -> 회원 번호, 책 번호 입력 -> 대출 또는 반납 -> 결과 글 -> 메뉴

## 안 하는 것

- 없는 책 번호 안내: loan-errors 장
- 대출 중인 책 거절 안내: loan-errors 장
- 책 목록 보기: book-list 장
- 빈 회원 번호 막기: borrow-command 장
- 저장 파일: file-store 장
