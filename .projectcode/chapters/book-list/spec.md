# book-list 책 목록 보기

종류: 기능
배울 것: 조회 유스케이스, 응답 모델

## 먼저 볼 문제

콘솔이 받은 Book으로 상태를 바꿀 수 있다
- 포트의 대출과 반납이 도메인 책을 그대로 돌려준다
- 그래서 콘솔 메뉴가 받은 책으로 대출과 반납을 직접 부를 수 있다
- 포트를 거치지 않고 바꾼 상태는 저장되지도 않는다

```
Book book = loanUseCase.borrow(memberId, bookId);
book.returnBook();
System.out.println(book.getTitle() + " 대출했습니다");
```

## 할 일

- S1 메뉴에 3 목록을 더한다. 고르면 책마다 책 번호, 제목, 대출 상태를 한 줄씩 찍는다. 대출 상태는 대출 가능 또는 대출 중이다
- S2 목록은 상태를 바꾸지 않는 조회 유스케이스다. 들어오는 포트로 열고 나가는 포트의 전체 찾기로 읽는다. 메모리 저장과 파일 저장 모두 전체 찾기를 한다
- S3 들어오는 포트는 도메인 책 대신 응답 모델을 돌려준다. 응답 모델은 책 번호, 제목, 대출 여부만 담고 상태를 바꾸는 메서드가 없다
- S4 콘솔 메뉴와 두 번째 입구는 도메인 책을 모른다

## 실행 예시

```
1 대출  2 반납  3 목록  0 종료
> 1
회원 번호: M1
책 번호: B1
객체지향의 사실과 오해 대출했습니다
1 대출  2 반납  3 목록  0 종료
> 3
B1 객체지향의 사실과 오해 대출 중
B2 클린 아키텍처 대출 가능
B3 도메인 주도 설계 첫걸음 대출 가능
```

## 흐름

메뉴 3 -> 조회 유스케이스 -> 나가는 포트 전체 찾기 -> 책을 응답 모델로 바꾸기 -> 메뉴가 한 줄씩 찍기

## 그대로인 것

- 대출, 반납, 종료의 동작과 결과 글은 file-store와 같다
- 두 번째 입구의 실행 결과는 file-store와 같다
- 대출 중인 책을 다시 대출하면 오류로 멈춘다

## 안 하는 것

- 대출 요청 검사: borrow-command 장
- 대출 실패 메시지: loan-errors 장
