# 개념

## 선수 지식

- 자바: 클래스, 인터페이스, enum, record, 예외
- 자바: 컬렉션(List, Map), 람다, 패키지
- DDD 전술 설계: 엔티티, 값 객체, 애그리거트, 리포지터리
- 계층 구조, 의존성 역전

## 배울 것과 처음 나온 장

| 배울 것 | 장 |
|---|---|
| 폴더 구조, 이클립스 실행 | project-setup |

| 들어오는 포트, 드라이빙 어댑터, 테스트도 입구 | use-case-port |
| 나가는 포트, 드리븐 어댑터 | store-port |
| domain, application, adapter 패키지, 의존 방향, Main 조립 | hexagon-packages |
| 어댑터 갈아 끼우기, 저장 모델 매핑 | file-store |
| 조회 유스케이스, 응답 모델 | book-list |
| 입력 모델, 입력 검사 위치 | borrow-command |
