결과물: 대출, 반납, 연체 알림이 되는 순수 자바 콘솔 도서 대출 프로그램

## 미룬 것

- 파일 일괄 입력 어댑터: 장 정하지 않음
- HttpServer 어댑터: 장 정하지 않음

## 하지 않는 것

- Spring 같은 프레임워크와 Gradle, Maven 같은 빌드 도구
- 화면, HTTP, JSON
- DDD 전략 설계: 바운디드 컨텍스트, 도메인 이벤트, 사가, CQRS
- 내려받아야 하는 라이브러리. JUnit jar와 13장의 ojdbc jar만 미리 복사해 쓴다
