# 도서 대출로 배우는 헥사고날 아키텍처

목표: 계층형 코드에서 문제를 겪고 포트와 어댑터로 하나씩 고친다
대상: 자바 기초와 ddd-example을 배운 학생
결과물: 대출, 반납, 연체 알림이 되는 순수 자바 콘솔 도서 대출 프로그램

| 번호 | 장 | 종류 | 배울 것 | 상태 | task | 사진 |
|---|---|---|---|---|---|---|
| 1 | project-setup 프로젝트 뼈대 | 기능 | 폴더 구조, 이클립스 실행 | 완료 | 2 | 3 |
| 2 | layered-loan 계층형 대출 | 기능 | 문제의 출발점이 되는 계층형 코드 | 완료 | 4 | 5 |

## 미룬 것

- 파일 일괄 입력 어댑터: 장 정하지 않음
- HttpServer 어댑터: 장 정하지 않음
- 오라클 저장 어댑터: 장 정하지 않음

## 하지 않는 것

- Spring 같은 프레임워크와 Gradle, Maven 같은 빌드 도구
- 화면, HTTP, JSON
- DDD 전략 설계: 바운디드 컨텍스트, 도메인 이벤트, 사가, CQRS
- 내려받아야 하는 라이브러리. 검증용 JUnit jar만 미리 복사해 쓴다
- 저장 파일이 깨졌을 때 알리기
- 반납 요청 입력 모델
- 회원 번호 모양 검사
- 실패 종류마다 다른 안내 글
- 직접 만든 예외 클래스
- 예전 모양 저장 파일 읽기
