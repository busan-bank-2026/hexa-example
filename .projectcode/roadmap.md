# 로드맵

강의: 도서 대출로 배우는 헥사고날 아키텍처
목표: 계층형 코드에서 문제를 겪고 포트와 어댑터로 하나씩 고친다
대상: 자바 기초와 ddd-example을 배운 학생
결과물: 대출, 반납, 연체 알림이 되는 순수 자바 콘솔 도서 대출 프로그램

## 선수 지식

- 자바: 클래스, 인터페이스, enum, record, 예외
- 자바: 컬렉션(List, Map), 람다, 패키지
- DDD 전술 설계: 엔티티, 값 객체, 애그리거트, 리포지터리
- 계층 구조, 의존성 역전

## 학습 목표

- 들어오는 포트와 드라이빙 어댑터
- 나가는 포트와 드리븐 어댑터
- 육각형 패키지와 의존 방향, Main에서 손으로 조립하기
- 어댑터 갈아 끼우기: 저장, 시계, 알림
- 경계를 넘는 모델: 입력 모델, 응답 모델, 저장 모델 매핑
- 경계를 넘는 실패: 도메인 예외를 어댑터가 메시지로 바꾸기
- 의존 방향을 테스트로 지키기

## 진행 방식

- 따라치기: 헥사고날 코드다. 학생이 직접 친다
- 붙여넣기: 헥사고날이 아닌 기반 코드다. 완성본을 복사한다
- 문제가 적힌 장은 문제를 먼저 실행해 보고 고친다

## 미룬 것

- 파일 일괄 입력 어댑터
- HttpServer 어댑터

## 하지 않는 것

- Spring 같은 프레임워크와 Gradle, Maven 같은 빌드 도구
- 화면, HTTP, JSON
- DDD 전략 설계: 바운디드 컨텍스트, 도메인 이벤트, 사가, CQRS
- 내려받아야 하는 라이브러리. JUnit jar와 13장의 ojdbc jar만 미리 복사해 쓴다
